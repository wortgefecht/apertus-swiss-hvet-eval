# Reference Sources

Version: **0.2.0**
Status: **Hackathon benchmark source set**
Project: **Apertus Swiss HVET Eval**

## 1. Purpose

This document defines the authoritative source base used to establish the expected facts for the benchmark.

The evaluation concerns **Swiss Professional Education** (*höhere Berufsbildung*). Expected facts should therefore be based primarily on current Swiss federal sources rather than secondary descriptions, training-provider websites, general reference works, or model-generated summaries.

The benchmark evaluates Apertus against the regulatory and institutional situation applicable from **1 October 2026**.

This reference date is particularly important because several changes concerning Swiss Professional Education enter into force on that date.

---

## 2. Source Hierarchy

Where several sources address the same issue, the following hierarchy should normally be applied:

1. **Federal legislation and ordinances published in Fedlex**
2. **Current SERI / SBFI information specific to the subject**
3. **SERI / SBFI official registers, implementation guidance, and FAQs**
4. **Other Swiss federal authorities**
5. **Official or institutionally mandated Swiss education information services**
6. **Other sources only where no authoritative source resolves the issue**

Where a lower-ranked source conflicts with current federal legislation, the legislation takes precedence.

A general information page should not override a more specific current regulation, official register entry, or implementation document.

## 3. Core Federal Sources

### SRC-01 — Professional Education / Höhere Berufsbildung

**Institution:** State Secretariat for Education, Research and Innovation (SERI / SBFI)
**Title:** *Höhere Berufsbildung*
**Type:** Official federal overview
**Priority:** Core

**Use for:**

- definition and scope of Swiss Professional Education,
- position within the Swiss tertiary education system,
- distinction between federal examinations and programmes at Professional Education Institutions,
- general structure of the sector.

The SBFI identifies two principal components of Swiss Professional Education:

- Federal Professional Examinations and Advanced Federal Professional Examinations,
- programmes at Professional Education Institutions / Höhere Fachschulen.

**Locator:** SBFI → Bildung → Höhere Berufsbildung

## 9. Source Selection Rules for Benchmark Cases

Each benchmark case should reference the **smallest sufficient set of authoritative sources**.

A case should not accumulate sources merely to make the expected answer appear better supported.

Recommended approach:

- use **one primary source** where it clearly resolves the question;
- use **two sources** where the case involves both a legal rule and its implementation;
- add further sources only where they resolve a genuine ambiguity.

Examples:

**Definition of Professional Education**

`SRC-01`

**Is an HF diploma a university bachelor's degree?**

`SRC-01 + SRC-03 + SRC-05`

**Who recognises an HF programme?**

`SRC-03 + SRC-06`

**What changes for NDS HF on 1 October 2026?**

`SRC-08 + SRC-09 + SRC-12`

**Does NQR level 6 make two qualifications equivalent?**

`SRC-05`

**Does a specific qualification currently exist and what is its official title?**

`SRC-04`

## 10. Time and Version Control

Because the benchmark evaluates factual knowledge at a particular point in time, each source used in a benchmark case should be treated as versioned evidence.

For dynamic web pages, record:

- source ID,
- page title,
- institution,
- canonical URL,
- date accessed,
- relevant update date if shown.

For legislation, record:

- systematic collection number,
- canonical Fedlex URL,
- version in force for the benchmark reference date,
- effective date.

Because v0.1.0 is documented before the 1 October 2026 reference date, the consolidated Fedlex versions used for scoring must be re-verified on or after that date before the affected benchmark cases are finalised.

The core evaluation reference date is:

> **1 October 2026**

Information that was correct before this date but became obsolete due to the 2026 reform must not be treated as current.

If a model explicitly distinguishes between the previous and current legal situation, both parts should be checked against the corresponding source versions.

---

## 11. Excluded Source Types

The following should not be used to establish reference-standard expected facts unless an exceptional reason is documented:

- Wikipedia,
- commercial education-provider websites,
- private career portals,
- blogs,
- news articles summarising official changes,
- social media posts,
- unsourced presentations,
- AI-generated summaries,
- search-engine snippets.

Such material may help identify potential benchmark questions but should not determine the reference answer.

---

## 12. Adding New Sources

New sources may be added during benchmark development where a test case requires them.

Each new source should receive a stable identifier:

`SRC-18`, `SRC-19`, …

Secondary sources should use:

`SRC-S02`, `SRC-S03`, …

Adding a source does not require a methodological version change unless the source changes the interpretation or scoring of existing benchmark cases.

Any source added **after evaluation of the affected case** should be documented explicitly to avoid retrospective adjustment of the reference standard.
